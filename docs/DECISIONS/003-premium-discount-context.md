# 003 — Premium/Discount as context

- **Decision:** Premium/Discount is context/confirmation, not an independent
  entry trigger. EQ reaction/reclaim is not mandatory unless a specific
  approved setup requires it. Source: [U-PD-001].
- **Reason:** Preserve the explicit user clarification instead of inferring
  universal EQ-entry behavior from a textbook or external implementation.
- **Consequence:** Later Context/Acceptance specs define its use. Preserve
  [D-DD-MSB-001]'s ordinary HTF side blocks separately; context alone cannot
  create an entry or acceptance/risk approval.
- **Date:** 2026-09-12.
