# 004 — Market Structure as derived state

- **Decision:** Model Market Structure as persistent derived market state;
  do not force the complete structure model into a boolean PatternResult.
- **Reason:** Direction, structural responsibility, protection, invalidation,
  scale and causal confirmation relationships evolve across evaluations.
- **Consequence:** The future engine needs an explicit state/evidence contract
  separate from pattern flags. This records design intent only: no current
  Python API or architecture was changed. N-1–N-7 must be resolved first.
- **Date:** 2026-09-12.
